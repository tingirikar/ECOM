# INSTALL DEPENDENCIES

### backend/ dependencies
```
cd backend
npm install
cd ..
```
### frontend/ dependencies
```
cd frontend
npm install
cd ..
```

# RUN ECOM

### TERMINAL 1 : RUN backend/
```
cd backend
node seed.js
node server.js
```

### TERMINAL 2 : RUN frontend/
```
cd frontend
npm run dev
```
